# Optimizer Selection Guide

Choosing the right DSPy optimizer has a large impact on both result quality
and cost. This guide maps common scenarios to the recommended optimizer.

## Quick Selection Table

| Scenario | Recommended Optimizer |
|---|---|
| < 20 labeled examples | `BootstrapFewShot` |
| 20–200 examples, quality focus | `MIPROv2` |
| 200+ examples, high latency tolerance | `MIPROv2` with `num_trials=50+` |
| Need interpretable prompts | `MIPROv2` |
| Minimize LLM calls during optimization | `BootstrapFewShot` |
| Fine-tuning a smaller model | `BootstrapFinetune` |

## BootstrapFewShot

Generates few-shot examples by running the pipeline on training data and
keeping examples where the metric is satisfied.

```python
import dspy
from dspy.teleprompt import BootstrapFewShot


def validate_answer(example, pred, trace=None):
    return example.answer.lower() == pred.answer.lower()


optimizer = BootstrapFewShot(
    metric=validate_answer,
    max_bootstrapped_demos=4,   # Max few-shot examples per predictor
    max_labeled_demos=16,       # Max labeled examples to draw from
)

optimized_program = optimizer.compile(
    student=my_program,
    trainset=trainset,
)
```

**Pros:** Fast, low cost, works with tiny datasets.
**Cons:** Only optimizes demonstrations, not instructions.

## MIPROv2

Optimizes both instructions and few-shot demonstrations using a Bayesian
search over candidate prompts.

```python
from dspy.teleprompt import MIPROv2

optimizer = MIPROv2(
    metric=validate_answer,
    auto="medium",          # "light", "medium", or "heavy"
    num_threads=8,          # Parallel evaluation threads
)

optimized_program = optimizer.compile(
    student=my_program,
    trainset=trainset,
    valset=valset,          # Separate validation set for Bayesian search
    requires_permission_to_run=False,
)
```

**Pros:** Best quality, optimizes both instructions and demos.
**Cons:** Higher cost (many LLM calls during optimization).

### `auto` Parameter

| Setting | Trials | Use When |
|---|---|---|
| `"light"` | ~10 | Quick experiments, cheap models |
| `"medium"` | ~25 | Balanced quality/cost |
| `"heavy"` | ~50 | Production, maximize quality |

## BootstrapFinetune

For fine-tuning a smaller model using demonstrations generated by a stronger teacher:

```python
from dspy.teleprompt import BootstrapFinetune

optimizer = BootstrapFinetune(metric=validate_answer)
optimized = optimizer.compile(
    student=my_program,
    teacher=teacher_program,  # Stronger model generates training data
    trainset=trainset,
)
```

## Evaluation Before Optimization

Always establish a baseline before running any optimizer:

```python
evaluator = dspy.Evaluate(
    devset=devset,
    metric=validate_answer,
    num_threads=4,
    display_progress=True,
)

baseline_score = evaluator(my_program)
print(f"Baseline: {baseline_score:.1%}")

optimized_program = optimizer.compile(...)
optimized_score = evaluator(optimized_program)
print(f"Optimized: {optimized_score:.1%}")
print(f"Improvement: {optimized_score - baseline_score:+.1%}")
```
